API del menú de la cafetería de la universidad, hecha con Django REST Framework.

## Cómo ejecutarla

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    python manage.py runserver

## Rutas

- GET /api/estado/
- GET /api/platos/
- GET /api/platos/<id>/
- POST /api/platos/
